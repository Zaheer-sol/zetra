# Pilot checklist

Use this checklist to learn whether Zetra reduces payment reconciliation work for a small business.
Start with simulated payments; a funded network test is a separate activity and requires verified
configuration and explicit operator approval.

## Participants

Recruit a few small businesses that receive stablecoin payments and currently match them to
invoices by hand. Ask about their existing process before demonstrating Zetra.

## Product session

1. Create a workspace and add a receiving wallet on a configured network.
2. Create a customer and invoice with a clear payment purpose.
3. Use a simulated exact payment and inspect the match, invoice, and accounting entry.
4. Optionally demonstrate an unmatched or partial payment and record how the participant would
   resolve it.
5. Ask what is unclear, what evidence they need before trusting the books, and what remains missing.

Label simulated activity accurately. Do not describe a simulation as a real transfer, and do not
claim live payment processing until an end-to-end network test has been completed.

## Record

With the participant's consent, note the date, business type, task completed, time spent, observed
problems, and their feedback. Do not publish a name, quote, transaction detail, or other identifying
information without permission.
